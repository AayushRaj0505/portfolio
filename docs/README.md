# 📖 Documentation Index - Aayush Raj Portfolio

Welcome to the documentation directory! Here is where you can find quick instructions for maintaining, editing, and expanding your portfolio website.

- **[Full Architecture & Customization Guide](./DOCUMENTATION.md)**: Explains the entire file tree, how to update videos, images, text, education, projects, and skills.
- **[Source Code Data Hub](../src/data/portfolioData.ts)**: Where all your personal info, projects, and skills are stored in TypeScript.

---

### Quick Editing Checklist
- **Change Education or Bio:** Edit `/src/data/portfolioData.ts` and `/src/components/AboutSection.tsx`.
- **Change Resume:** Edit `/src/components/ResumeModal.tsx`.
- **Add New Projects:** Edit `/src/data/portfolioData.ts` and `/src/components/WorkSection.tsx`.
- **Update Skills:** Edit `SKILLS` array in `/src/data/portfolioData.ts`.
- **Change Hero Photos:** Replace files in `/src/assets/images/` or edit `/src/components/Hero.tsx`.
